SurfaceShift: Real-Time Screen Restyling
with Latent Diffusion

Evan Smith

Local-first research demo · v0.5 · August 2026

Code Validation Research Notes

Abstract

SurfaceShift restyles a live visual source—a captured browser tab, camera, or video—into a chosen material world while it moves. The system samples 704×704 frames at 10 Hz, keeps exactly one low-latency request in flight against a distilled image-to-image diffusion model (FLUX.2 [klein]), and presents results through evenly paced frame-pair interpolation plus a bounded, separately disclosed global-translation warp that carries source motion between model results. Measured live runs hold roughly 4 native model frames per second with about 8 independently changing presented frames per second; exact unwarped source/result pairs remain available for audit. The demo runs entirely from localhost with user-supplied credentials, and an optional on-device Apple Silicon fallback sends no frames off the machine.

Method

Capture is decoupled from inference: sampling continues while a request is in flight, and only the newest waiting frame is ever dispatched (latest-frame-wins). This avoids both stale lockstep capture and an unbounded cloud queue. A 48×48 luma search estimates conservative global source translation and immediately moves the last model image in the same direction; these warp updates are labeled separately from model output and are excluded from the exact-pair audit mode. 

moving source
  → sample at 10 fps
  → estimate conservative global source translation
  → retain only the newest waiting frame
  → one low-latency diffusion request at a time
  → evenly pace the interpolation pair
  → warp the latest model image between results when motion is reliable
  → generated canvas + 30 fps recording compositor

Disclosures

Cloud processing. FLUX.2 mode sends sampled frames to fal.ai for generation. Share only windows you are comfortable processing in the cloud.

Local-only by design. This repository hosts no live AI. Cloud inference starts only from localhost with your own fal key and your selected per-session limit.

Your key, your usage. Every clone supplies its own credentials. This project exposes no owner-funded public inference endpoint.
